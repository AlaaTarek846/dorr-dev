## ⚠️ معيار الجودة (نفس معيار الرحلات)

**ممنوع Polling.**
- أي حاجة بتتغير والتطبيق مفتوح تيجي **حدث لحظي** (Pusher/Reverb). مثال: واجب جديد، أو تسليم، أو مهمة اتسندت، أو حالة مهمة اتغيرت.
- أي حاجة لازم توصل والتطبيق مقفول تيجي **Push** (OneSignal).
- المواعيد المعروفة (موعد التسليم، أو بداية اختبار) تتحسب **بساعة الجهاز**.
- ريكويست واحد للحاق عند فتح التطبيق أو رجوع الاتصال.
- التفاصيل في [rides_tasks.md](rides_tasks.md).

**الصلاحيات في الخادم مش في الواجهة بس** (القسم 07):
- كل endpoint بيتأكد من الدور ونطاقه (الجروب، الفترة، المجموعة الفرعية، المشروع).
- إخفاء زرار في التطبيق مش حماية.

**الجروب العادي ما يتأثرش.** كل اللي هنا بيشتغل بس لما نوع الجروب `education` أو `work`. واختبارات الشات الحالية لازم تفضل شغالة.

## قواعد الشغل على الملف

1. **قبل ما تبدأ مهمة:** غيّر `👤 —` لاسمك وجنبه `🚧`، واعمل commit و push على طول.
   - المهمة اللي عليها اسم حد تاني ما تشتغلش عليها.
2. **لما تخلص:**
   - `- [ ]` تبقى `- [x]`، و`🚧` تبقى `✅ YYYY-MM-DD` ومعاها الـ commit.
   - المهمة ما تتعلمش خلصانة غير لما يتوفر الآتي:
     - الباك إند واختباراته.
     - شاشات الأندرويد بالعربي والإنجليزي.
     - لوحة التحكم لو المهمة محتاجاها.
     - تحديث `docs/modules/chat/API.md`.
     - `composer test` شغال.
3. **بيلد الأندرويد (Gradle) ما يتعملش غير بطلب صاحب المشروع.**
4. **التصميم:** نفس ستايل شاشات الشات الموجودة (`Ch*`، و`SubHeader`، والهيدر الوردي، والأنيميشن).
5. **أي سعر أو حد أو مهلة** يتحط من إعدادات الشات في لوحة التحكم، مش Hard-code.

**الرموز:**
- ⚙️ الباك إند.
- 🎨 الواجهة (أندرويد + لوحة).
- 📝 ملاحظة عن الموجود، أو قرار مستني.
- 📄 السيناريو أو القسم في الوثيقة.
- 👤 مين ماسك المهمة.

## الموجود في الشات وهنبني عليه (ما يتعادش)

| الموجود | فين | هيتستخدم في |
|---|---|---|
| الجروبات والأعضاء والأدوار (owner / admin / member) | `chat_groups`، و`chat_participants`، و`GroupService` | الأساس. الأدوار الجديدة بتتبني فوقها (GR-004). |
| روابط الدعوة بمدة، وطلبات الانضمام بموافقة | `invite_token`، و`invite_expires_at`، و`chat_group_join_requests` | GR-003 (ناقص «السبب» في الطلب). |
| نقل الملكية | `groups/{c}/owner` (فوري) | GR-005 (المطلوب: المرشح يقبل الأول). |
| حذف الجروب للكل | `DELETE groups/{c}` (soft delete) | GR-006 (ناقص الأرشفة وفترة الاسترداد). |
| المجتمعات (جروب فيه جروبات) | `chat_communities`، و`CommunityService` | الفترات والمجموعات الفرعية والمشروعات (D2). |
| الاستطلاعات، والقرارات، والتقويم | `poll`، و`chat_group_decisions`، و`chat_calendar_items` | الاستبيانات، والاعتمادات، والجلسات، والاجتماعات. |
| مهامي (شخصية) و«رسالة ← مهمة» بالذكاء الاصطناعي | `chat_tasks`، و`TaskService` | فكرة GR-038. مهام الجروب **جدول جديد**، لأن `chat_tasks` شخصية. |
| الملفات والوسائط والبحث | `chat_messages`، وMedia | GR-008. لازم إعادة فحص الصلاحية عند كل تنزيل. |
| المكالمات الجماعية | LiveKit (`CallService`) | الجلسات واجتماعات أولياء الأمور. |
| DORR AI وخطته | `AiChatUsageGuard`، وADR-013 | المساعد، وتحضير الدروس، وخطة التقوية، والمحاضر. |
| شاشة الدفع الموحدة | `wallet/checkouts` + `CheckoutPurpose` | أي حاجة مدفوعة (D6). |
| إخفاء الأعضاء (مدفوع) | `ParticipantDirectory::isHiddenFrom()` | ممكن يتفعّل في التعليم (خصوصية الطلاب). |
