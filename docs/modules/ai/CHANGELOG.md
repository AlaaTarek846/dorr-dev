# AI — Changelog

## [Unreleased]

### Fixed (2026-11-11, bugs found while writing the screen guides)
- **Money / sites:**
  - A paid site request moved to rejected or cancelled is refunded once, as spend-only wallet credit. Instalments become `refunded`, a system line and a notification go to the customer.
  - Admin site delete is refused (422) while a hosting still has paid time (`AiSiteHosting::hasPaidTimeLeft`).
  - AR and World amounts use the currency's real decimals (`CurrencyDecimals`, admin-only `currency_decimals`).
  - AR devices store the real platform (form select, `X-Platform`).
  - The site request conversation (admin, Android, iOS) is real-time: event `ai_site_request.changed`, no timers.
- **Logs / monitoring / privacy:**
  - Writers for reliability metrics (`ai:aggregate-reliability`, hourly), safety scans, security events (rate limit, blocked owner) and project context.
  - `http_status` in provider logs.
  - Provider health writes on state change only, with `recovering`.
  - Retention also purges provider health, code executions, audit events and safety scans.
  - Safety event reasons and verification drafts are redacted (`minimizedForLog`).
  - `ai_requests.error_code` and `retry_count` are written.
  - Admin resources send `owner.phone`.
  - The benchmark run is marked failed when it crashes.
- **Policies / engine:**
  - Data policies are applied (`AiPersonalDataPolicy`: consent → no profile, no external provider → masking), and so are provider-data-rule `transformation_rules`.
  - Safety action `require_confirmation` asks the person to send the same text again within 30 minutes.
  - Routing `selection_strategy` is applied (priority, round robin, latency); `cost_optimized` was removed.
  - A switched-off default policy falls back to `ai.routing.defaults`.
  - Security-policy switches are shown as always enforced.
  - Duplicate variant code → validation error.
  - Knowledge source approve reactivates it.
  - The free trial is one-time (`trial_ended`).
  - MRR and monthly revenue are given per currency.
  - `SearchFilterTrait` skips a relation search with empty columns.
- Tests: `AiMonitoringWritersTest` (16), `AiPolicyEnforcementTest` (12), plus cases in the site, AR, World, variant and subscription tests
