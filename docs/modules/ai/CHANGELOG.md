# AI — Changelog

## [Unreleased]

### Added
- **DORR AI's own tools, 2026-10-14 (spec 121–151, 314–332, 344):** memory (`AiMemoryService`, «افتكر إن…» in a message or the memory screen; secrets refused; on/off), "continue in a new chat" with a Context Capsule (`AiContextContinuationService`), search by word and by meaning (`AiHistorySearchService`), the person's projects (`AiUserProjectService`), the outputs gallery (`AiOutputGalleryService`), evidence rules before an answer (`AiEvidencePlanner`) and system checks after it (`AiCitationValidator`: Qur'an references, source markers, arithmetic, dates, jurisdiction, «والله أعلم»), and a per-country switch for the whole DORR AI chat (`AiFeatureFlag::TARGET_SERVICE`). Controllers `AiMemoryController`, `AiHistoryController`, `AiUserProjectController` (user and provider routes). Migration `2026_10_14_110000_create_ai_memories_tables`. Admin: "service" target in AI feature flags. Benchmark cases for law freshness and feasibility math. Android: search, memory, projects, outputs, continue-in-a-new-chat and the carried-over context banner. Support's FAQ auto-reply now runs on `AiTaskRunner` too (`support.faq`, free). Tests: `AiAssistantToolsTest` (9), `SupportAutoReplyTest` (+1)
- **`AiTaskRunner`, 2026-10-14:** every AI call from another module (all of DORR Chat's AI tools, Discover's search, greetings, portal translations) now goes through the DORR AI chat's own pipeline — the admin's AI block, safety rules, routing policy, fallback and circuit breaker, the registered speech-to-text model, and the usage log — instead of calling the default provider directly. Migration `2026_10_14_100000_add_source_to_ai_requests_table` (`ai_requests.source`); `AiRequestResource.source`; admin "AI Requests" screen: a Source column and filter (`?source=ai_chat|tools|<tool>`). Tests: `ChatAiSameSystemTest` (8)
- **DORR AI safety layer (spec 350–362), 2026-10-08:** `Modules/AI/app/Safety/` — `RiskClassifier` (a separate JSON classification call plus fixed Arabic/English keyword rules that decide alone when the model can't), `RiskAssessment`, `SafetyPolicyEngine` (rules as instructions before the answer; after it, the approved referral sentence and opening disclaimer from `lang/*/ai.php` `safety.*`, "optional" softeners removed, the model's own copy of the fixed sentence dropped). Applied to the AI chat (`AiChatService::sendMessage`) and to every free answer in DORR Chat. Migration `2026_10_08_100000_add_safety_to_ai_messages` (`ai_messages.safety` json)
- Speech to text: `AiGateway::transcribe()` (OpenAI / Groq Whisper, Google Gemini), `AiProviderRepository::resolveForTranscription()`, config `transcription_model` per provider and `transcription_timeout` (2026-10-04)
- Module documentation
