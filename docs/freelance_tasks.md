## ⚠️ معيار الجودة (نفس معيار الرحلات)

**ممنوع Polling.** أي حاجة بتتغير والتطبيق مفتوح تيجي **حدث لحظي** (Pusher/Reverb)، وأي حاجة لازم توصل والتطبيق مقفول = **Push (OneSignal)** بـ priority وttl. الأوقات المعروفة بساعة الجهاز. ريكويست واحد للحاق عند الفتح أو رجوع الاتصال. مفاتيح الاتصال من `realtime-config` السيرفر. التفاصيل في `docs/rides_tasks.md`.

## قواعد الشغل على الملف

1. **قبل ما تبدأ مهمة:** غيّر `👤 —` لاسمك وجنبه `🚧`، واعمل commit و push على طول. المهمة اللي عليها اسم حد تاني ما تشتغلش عليها.
2. **لما تخلص:** `- [ ]` ← `- [x]`، و`🚧` ← `✅ YYYY-MM-DD` مع اسم الـ commit أو الـ PR. **ما تتعلمش خلصانة** إلا لما يتوفر:
   - الباك إند **واختباراته** (نجاح، وفشل، ومنع غير المخوّل، وحالات حدودية).
   - الشاشات في الواجهات المعنية، وكل نص **عربي وإنجليزي**.
   - لوحة الـ admin لو المهمة محتاجاها.
   - تحديث `docs/modules/freelance/README.md` (وAPI.md للـ API).
   - `composer test` شغال، و`npm run build` لو اتلمس الويب، و`gradlew :app:compileDebugKotlin` لأي تطبيق اتلمس.
3. **بعد كل دفعة مهام:** شغّل `python docs/modules/freelance/make_status.py`.
   - بيقرا العلامات `[x]` من الملف ده، ويكتب `DORR_Freelance_Platform_Requirements_v4_405_status.docx` جنب الأصل: **أخضر = منجز، أحمر = مخطط ولم يُنجز، رمادي = مدموج أو محذوف أو مرفوض**، ويحدّث جدول **التقدم** أعلى الملف تلقائياً.
   - ما يحتاجش `python-docx`. الأصل (`DORR_Freelance_Platform_Requirements_v4_405.docx`) ما بيتلمسش.
4. **NEEDS-DECISION / NEEDS-LEGAL:** ما تنفذوش بتخمين.
5. **قواعد ثابتة:**
   - أي سعر أو نسبة أو مهلة أو حد = **Policy/Config من الداشبورد**، مش Hard-code.
   - أي أمر مالي فيه **Idempotency-Key**.
   - أي ميزة ليها **مفتاح** في `FreelanceFeatures` (مقفول لو مفيش قاعدة)، حسب الدولة والمحافظة.
   - **قرار حساس (حظر/عقوبة/نزاع/تجميد فلوس) = موظف مخوّل + اعتراض.** الذكاء الاصطناعي بيقترح بس.
   - ما يتنسخش شعار أو تصميم أو نص من منصة تانية.
