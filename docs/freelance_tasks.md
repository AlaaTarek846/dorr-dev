# مهام تطوير خدمة Freelance — استراتيجية المنتج (FS)

> المصدر: `Dorr_Freelance_Product_Strategy_AR.docx` (مقترحات منتج) + مراجعتنا لـ [`docs/modules/freelance/OVERVIEW.md`](modules/freelance/OVERVIEW.md) والكود الموجود.
> الوثيقة مقترحات مش مواصفات نهائية. الملف ده بيحوّلها لمهام تتنفذ، وبيفصل **اللي موجود فعلًا** عن **اللي ناقص**، وفيه **إضافات وتحسينات** على الوثيقة (متعلّم عليها بـ ➕).
> **الملف ده المرجع الوحيد لحالة الشغل.** أكتر من حد شغال عليه، فالتزم بالقواعد اللي تحت.

## معيار الجودة (ملزم)

- **ممنوع Polling.** أي حاجة بتتغير والتطبيق مفتوح = حدث لحظي (Pusher/Reverb)، والتطبيق مقفول = Push (OneSignal). ريكويست واحد للحاق عند الفتح أو رجوع الاتصال. (تفاصيل في [`docs/rides_tasks.md`](rides_tasks.md)).
- **الباك إند:** `Route → Controller → Service → Repository → Model` + Form Request + API Resource، داخل `Modules/Freelance`. كل ميزة جديدة **ليها مفتاح تشغيل لكل دولة** (`freelance.feature:<اسم>`، مفيش قاعدة = مقفول) وصلاحية أدمن (RBAC) وتسجيل Audit.
- **الفلوس بالدولار** في محفظة freelance (`FreelanceMoney`)، إلا لو عملة المستخدم المحلية هي الدولار فمحفظته المحلية. أي مهمة فيها فلوس تمر على الدفتر المالي (`FreelanceEarnings` / `MilestonePayments`) ومتعملش مسار مالي موازي.
- **أندرويد ← iOS في نفس المهمة:** `androidApp` ↔ `iosApp`، `freelanceApp` ↔ `freelanceAppIOS` (قواعد التوأم في `AGENTS.md`). الـ strings من XML الأندرويد بس، وعربي + إنجليزي.
- **الذكاء الاصطناعي بيقترح بس:** مفيش AI بيحرر فلوس أو يحسم نزاع أو يوقف حساب أو يغيّر اتفاق من غير موافقة صريحة.
- **المهمة مش خلصانة** غير لما يتوفر: الباك إند + اختباراته، شاشات التطبيقات المعنية (أندرويد + iOS)، لوحة الأدمن لو محتاجاها، تحديث `OVERVIEW.md` و`API.md` و`docs/10-CHANGELOG.md`، و`composer test` شغال، و`compileDebugKotlin` ناجح لأي تطبيق اتلمس.

## قواعد الشغل على الملف

1. قبل ما تبدأ: غيّر `👤 —` لاسمك وجنبه `🚧`، واعمل commit/push عشان محدش ياخدها معاك. اللي عليها اسم حد تاني ما تشتغلش عليها.
2. لما تخلص: `- [ ]` ← `- [x]`، شيل `🚧`، واكتب `✅ YYYY-MM-DD` ومعاها الـ PR.
3. الحجم: **S** (يوم أو أقل) · **M** (2–4 أيام) · **L** (أسبوع+) · **XL** (يتقسم لمهام أصغر قبل البدء).
4. «يعتمد على» معناها: ما تبدأش قبل ما اللي اتذكر يخلص.
