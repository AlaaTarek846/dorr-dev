### Fixed
- **Admin → Chat → Channels would not open (2026-10-22):** the search placeholder used `@handle`, which vue-i18n treats as a linked message and crashed the page. The `@` is escaped in ar/en.


- **Freelance — file check on every upload (FL-1205, 2026-10-24):** the rule `CleanUpload` (`Modules/Freelance/app/Rules/CleanUpload.php`, backed by `Services/Security/UploadScanner`) is on all nine freelance uploads (portfolio, certificates and ID documents, offer attachments, deliveries, dispute evidence, chat files, project attachments, avatars). It reads the file's real bytes, not its name, and refuses: a blocked extension anywhere in the name (`report.pdf.exe`), a program / script / page that runs code (by content), a name that does not match the bytes (a "photo.png" that is not an image), a PDF with active content (JavaScript, launch actions), an Office file with macros, and a zip that hides a program or macros, is unreadable, has a path escape or is a bomb (entries, unpacked size, ratio). A refused file answers 422 `freelance.file_rejected` (en/ar), is never stored and is written to the log (who, what, why). **This is not an antivirus**: for that, set `FREELANCE_CLAMAV_ENABLED=true` with `FREELANCE_CLAMAV_HOST|PORT|TIMEOUT` and the file is also streamed to a ClamAV daemon (INSTREAM); when the daemon cannot be reached the upload is refused (`FREELANCE_CLAMAV_FAIL_CLOSED`, default true; message `file_scan_unavailable`). Delivery types are `jpg,jpeg,png,webp,gif,pdf,doc,docx,xls,xlsx,ppt,pptx,txt,zip` (rar removed: it cannot be looked into). Tests: `FreelanceUploadScannerTest` (5); older tests now upload real PDF bytes.
- **Freelance — the evidence timeline of a dispute (FL-606, 2026-10-24):** `GET admin/v1/freelance-disputes/{uuid}/timeline` gives staff one list, oldest first, of everything on the project: the agreement's steps, every approval on record (FL-406), the work on the disputed part, each delivery with its files, what both sides said and showed in the dispute, the dispute's own steps (opened, appealed, decided, resolved) and the chat between the two (up to 500 lines). `GET …/timeline/export` is the same as a CSV (cells that start with `=`, `+`, `-`, `@` are neutralised) and `GET …/deliveries/{delivery}/files/{media}` opens a delivered file (inline for images, `nosniff`, `no-store`). Reading and exporting need `freelance-disputes.view` and are written to the audit log (`freelance.dispute.timeline_viewed|timeline_exported`). Admin page (Freelance → Disputes → a case): an "Evidence timeline" block with a show/hide button, a colour badge per kind, file links and "Download CSV". Delivered files now keep the name the person gave them (not the stored one) in lists, the timeline and downloads. Test: `FreelanceDisputeTest`.
